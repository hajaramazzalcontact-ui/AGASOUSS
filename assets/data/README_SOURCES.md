## AZUL AGADIR - Attribution des Images

Toutes les photos utilisées dans AZUL AGADIR proviennent de sources libres de droits avec crédits explicites.

### Sources Utilisées

| Source | Licence | URL |
|--------|---------|-----|
| **Unsplash** | CC0 (Domaine Public) | https://unsplash.com |
| **Pixabay** | CC0 (Domaine Public) | https://pixabay.com |
| **Pexels** | CC0 (Domaine Public) | https://pexels.com |
| **Wikimedia Commons** | Multiples (CC-BY-SA) | https://commons.wikimedia.org |

### Utilisation des Images

Chaque image dans l'application affiche :
- **Source** : Unsplash, Pixabay, Pexels, etc.
- **Artiste/Photographe** : Nom du créateur
- **Lien** : Vers la page d'origine (si applicable)

### Format des Crédits

Les crédits s'affichent selon ce format :
```
© [Source] - [Artiste/Photographe] / [Titre optionnel]
```

**Exemple :**
```
© Unsplash - Ocean Vibes / Dolphins Swimming
```

## 🔒 Conformité Légale

### Droits d'Utilisation

✅ **Toutes les images sont autorisées pour :**
- Usage commercial
- Modification et adaptation
- Distribution et partage
- Affichage sur web et applications

❌ **Aucune image contient :**
- Visages identifiables de personnes (sauf en arrière-plan)
- Marques déposées protégées
- Contenus sensibles

### Mise à Jour des Photos

Si tu souhaites remplacer une photo :
1. Trouve une alternative sur Unsplash, Pixabay ou Pexels
2. Ajoute l'URL dans les données (JSON ou base de données)
3. Complète les crédits dans le fichier `photo_credit`
4. Mets à jour ce README

### Attributions Requises

Pour chaque image affichée :
```json
{
  "url": "https://images.unsplash.com/photo-XXX",
  "credit": "© Unsplash - Artist Name",
  "source": "Unsplash",
  "title": "Photo Title (optionnel)"
}
```
