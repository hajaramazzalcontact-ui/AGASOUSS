🎯 FLUX D'UTILISATION
=====================

1️⃣ INSTALLATION (5 min)
   └─ Lis INSTALL.md → Exécute les commandes

2️⃣ PREMIER LANCEMENT (2 min)
   └─ python scripts/init_db.py
   └─ streamlit run app.py
   └─ Ouvre http://localhost:8501

3️⃣ TEST (10 min)
   └─ Clique "Découvrir"
   └─ Filtre et ajoute au panier
   └─ Confirme réservation
   └─ Observe le code de confirmation

4️⃣ PERSONNALISATION (30-60 min)
   └─ Édite app.py pour les couleurs
   └─ Ajoute tes données dans demo_data.py
   └─ Ajoute tes restaurants/hôtels
   └─ Teste à nouveau

5️⃣ DÉPLOIEMENT (1-3h)
   └─ Lis DEPLOYMENT.md
   └─ Choix : Streamlit Cloud (gratuit) ou Docker (pro)
   └─ Configure domaine et SSL
   └─ Go live ! 🚀

🚀 GET STARTED
==============

# 1. Install (5 min)
cd azul-agadir
pip install -r requirements.txt
cp .env.example .env
# Edit .env and add ANTHROPIC_API_KEY

# 2. Launch (30 sec)
python scripts/init_db.py
streamlit run app.py

# 3. Open (instant)
http://localhost:8501

# 4. Test (10 min)
- Discover activities
- Add to cart
- Confirm booking
- See confirmation code

# 5. Deploy (1-3h)
- Read DEPLOYMENT.md
- Choose: Streamlit Cloud or Docker
- Configure domain
- Go live!
