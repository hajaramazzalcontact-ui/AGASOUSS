⚠️ AVANT DE COMMENCER :

1. Installer Git : https://git-scm.com/download/win
2. Créer un compte GitHub : https://github.com (gratuit)
3. Créer un repository GitHub vide (ne pas initialiser README)
4. Avoir la clé ANTHROPIC_API_KEY prête

════════════════════════════════════════════════════════════════════════════════
🚀 ÉTAPE 4 : DÉPLOYER SUR STREAMLIT CLOUD
════════════════════════════════════════════════════════════════════════════════

1. Aller sur : https://streamlit.io/cloud

2. Se connecter avec GitHub (Sign in with GitHub)

3. Cliquer "Create app"

4. Remplir :
   Repository : hajaramazzalcontact-ui/AZUL-AGADIR
   Branch : main
   Main file path : app.py

5. Cliquer "Deploy"

⏳ Attendre 2-3 minutes...

✅ L'app s'affiche !


════════════════════════════════════════════════════════════════════════════════
🔐 ÉTAPE 5 : CONFIGURER LES SECRETS
════════════════════════════════════════════════════════════════════════════════

1. Dans votre app Streamlit Cloud, cliquer ⚙️ Settings

2. Cliquer "Secrets"

3. Coller EXACTEMENT ceci :

ANTHROPIC_API_KEY = "sk-ant-votre-clé-API-ici"
DATABASE_URL = "sqlite:///azul_agadir.db"
ENVIRONMENT = "production"

4. Cliquer "Save"

5. L'app redémarrera automatiquement ✓

════════════════════════════════════════════════════════════════════════════════
🆘 SI ERREUR : "Permission denied (publickey)"
════════════════════════════════════════════════════════════════════════════════

Utiliser un Personal Access Token à la place du password :

1. GitHub Settings → Developer settings → Personal access tokens
2. Generate new token (classic)
3. Cocher : repo, read:user, user:email
4. Copier le token
5. Quand Git demande password, coller le token
