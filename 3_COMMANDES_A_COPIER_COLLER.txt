🚀 LES 3 COMMANDES À COPIER-COLLER DIRECTEMENT DANS POWERSHELL
════════════════════════════════════════════════════════════════════════════════

Avant de commencer :

✅ Ouvrir PowerShell dans le dossier azul-agadir/
✅ Avoir votre GitHub token (ou password) prêt
✅ Avoir créé le repo vide sur GitHub


════════════════════════════════════════════════════════════════════════════════
COMMANDE 1 : Ajouter le remote GitHub
════════════════════════════════════════════════════════════════════════════════

Copier et coller EXACTEMENT ceci :

git remote add origin https://github.com/hajaramazzalcontact-ui/AZUL-AGADIR.git

Appuyer sur ENTER

(Rien ne s'affiche, c'est normal ✓)


════════════════════════════════════════════════════════════════════════════════
COMMANDE 2 : Renommer la branche en main
════════════════════════════════════════════════════════════════════════════════

Copier et coller EXACTEMENT ceci :

git branch -M main

Appuyer sur ENTER

(Rien ne s'affiche, c'est normal ✓)


════════════════════════════════════════════════════════════════════════════════
COMMANDE 3 : POUSSER LE CODE SUR GITHUB
════════════════════════════════════════════════════════════════════════════════

Copier et coller EXACTEMENT ceci :

git push -u origin main

Appuyer sur ENTER
