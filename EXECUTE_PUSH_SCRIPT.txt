🔐 AUTHENTIFICATION GITHUB
════════════════════════════════════════════════════════════════════════════════

Quand Git demande votre username et password :

OPTION A : Utiliser votre username et password GitHub
   - Username : votre-username
   - Password : votre-password

⚠️ ATTENTION : GitHub n'accepte plus les password simples !


OPTION B : Utiliser un Personal Access Token (RECOMMANDÉ) ✅
   
   1. Aller sur GitHub → Settings → Developer settings → Personal access tokens
   2. Cliquer "Generate new token"
   3. Cocher les permissions :
      ✅ repo (accès complet aux repositories)
      ✅ user:email (lire l'email)
   4. Cliquer "Generate token"
   5. Copier le token (ressemble à : ghp_xxxxxxxxxxxxxxxxxxxxxxxxxxxx)
   6. Coller le token comme password quand Git demande

❌ SI ERREUR
════════════════════════════════════════════════════════════════════════════════

ERREUR : "git: command not found"
→ Git n'est pas installé
→ Téléchargez : https://git-scm.com/download/win (ou Linux/Mac)


ERREUR : "fatal: origin already exists"
→ Remote 'origin' existe déjà
→ Le script supprime l'ancienne, mais relancez-le


ERREUR : "Permission denied (publickey)"
→ Problème d'authentification SSH
→ Utiliser HTTPS avec Personal Access Token au lieu


ERREUR : ".env was added to the index"
→ Le fichier .env a été commité accidentellement
→ Vérifier que .env est dans .gitignore
→ Relancer le script
