🚀 SI VOUS PRÉFÉREZ LES COMMANDES MANUELLES
════════════════════════════════════════════════════════════════════════════════

Au lieu d'utiliser le script REPOUSSER_GITHUB.ps1, vous pouvez faire les
commandes manuellement une par une.


════════════════════════════════════════════════════════════════════════════════
PRÉALABLE : Ouvrir PowerShell
════════════════════════════════════════════════════════════════════════════════

Naviguer à : C:\Users\vams\Documents\Projet par défaut\azul-agadir

Clic DROIT → "Open PowerShell here"


════════════════════════════════════════════════════════════════════════════════
COMMANDE 1 : Ajouter les fichiers
════════════════════════════════════════════════════════════════════════════════

Copier-coller :

git add .

Appuyer sur ENTER


════════════════════════════════════════════════════════════════════════════════
COMMANDE 2 : Créer un commit
════════════════════════════════════════════════════════════════════════════════

Copier-coller :

git commit -m "Fix: Re-push all files to GitHub"

Appuyer sur ENTER

(Si rien ne change, c'est normal, il n'y a peut-être rien à commiter)


════════════════════════════════════════════════════════════════════════════════
COMMANDE 3 : POUSSER VERS GITHUB (LA PLUS IMPORTANTE)
════════════════════════════════════════════════════════════════════════════════

Copier-coller :

git push -u origin main --force

Appuyer sur ENTER

⏳ Attendre... (peut prendre 30 secondes)

🔐 PowerShell demandera :

Username for 'https://github.com': hajaramazzalcontact-ui

Password for 'https://hajaramazzalcontact-ui@github.com': [COLLER LE TOKEN]

Les caractères ne s'affichent pas, c'est NORMAL.

Appuyer sur ENTER quand vous avez collé le token.
