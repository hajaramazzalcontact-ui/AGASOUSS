🎯 VOS 3 PREMIÈRES ACTIONS
════════════════════════════════════════════════════════════════════════════════

ACTION 1 : Installer (5 minutes)
──────────────────────────────

Windows :
  cd azul-agadir
  python -m venv venv
  venv\Scripts\activate
  pip install -r requirements.txt
  copy .env.example .env

Linux/Mac :
  cd azul-agadir
  python3 -m venv venv
  source venv/bin/activate
  pip install -r requirements.txt
  cp .env.example .env


ACTION 2 : Configurer (2 minutes)
──────────────────────────────

Ouvrir le fichier .env
Ajouter votre clé API (gratuite) :

  ANTHROPIC_API_KEY=sk-ant-votreclé

Où obtenir la clé ?
  → https://console.anthropic.com/login
  → "API Keys" → "Create Key"
  → Copier et coller dans .env


ACTION 3 : Lancer (1 minute)
─────────────────────────

python scripts/init_db.py
streamlit run app.py

Puis ouvrir : http://localhost:8501

✅ DONE ! L'app marche ! 🎉
